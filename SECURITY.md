# Security Policy

This skill instructs an AI agent to audit code. It contains no executable server code; the scripts are read-only shell helpers.

Report a vulnerability in the skill or its scripts (for example a script that could leak secret values, run destructive commands, or follow unsafe paths) privately via GitHub: **Security -> Report a vulnerability**. Do not open a public issue for it.

Report incorrect or dangerous security guidance (a recommended fix that weakens security) as a normal issue using the "Wrong guidance" template.

Scope reminder: use the skill only on systems you own or are authorized to test.
